# IDS Software Suite (not included)

The IDS Software Suite is proprietary software from IDS Imaging Development Systems GmbH and is
not redistributed in this repository.

Download **IDS Software Suite 4.96.1 for Linux (Debian package archive)** for your architecture from
https://en.ids-imaging.com/download-peak.html (IDS account required) and place it here as:

- `ids-software-suite-linux-64-4.96.1-debian.tgz` (amd64)
- `ids-software-suite-linux-arm64-4.96.1-debian.tgz` (arm64)

The image build installs the package matching its architecture; see ../README.md.
